# 카카오페이 광고 × 전환(DB) 대시보드

광고센터에서 받은 다운로드 파일을 올리면 구글 시트에 기록하고, 전환(DB) 시트와 **소재번호로
맞춰** 소재별 소진 · DB · DB단가를 보여 줍니다.

```
광고센터 다운로드 파일 ─▶ 광고 시트 (당일 탭 / 마감 탭) ─┐
                          전환(DB) 시트 ─────────────────┴─▶ 소재별 집계 · 차트 · 복사용 리포트
```

## 쓰는 법

1. 광고센터 소재 화면 우측 상단 **다운로드**
2. 대시보드 **데이터 넣기** 에 올리고 **시트에 올리기**
3. 위쪽 **조회 모드**(당일 / 일별 / 기간)로 보기

날짜는 파일명(`_20260909_20260909`)에서 자동으로 읽습니다. 여러 날짜를 한꺼번에 올려도 되고,
**올린 파일에 든 날짜만** 갱신하므로 다른 날짜는 그대로 남습니다.

## 시트 구조

| 탭 | 담는 것 | 갱신 |
|---|---|---|
| `KakaopayToday` | 오늘 날짜 | 오늘 파일을 올릴 때마다 통째로 교체 |
| `KakaopayDaily` | 마감된 지난 날짜 | 그 날짜의 행만 교체. **다른 날짜는 안 건드림** |

**두 탭의 열은 똑같습니다.** 광고센터 다운로드 파일과 같은 구성이고, 날짜 열 이름만 `일자` 입니다.

```
일자 · 소재 · ON/OFF · 상태 · 광고그룹 · 광고상품 · 소진비용 · 노출수 · 클릭수 · 클릭률 · 도달수 · eCPM · CPC
```

- 파일의 `시작일` `종료일` 은 **캠페인 게재 기간**이라 성과와 무관해 넣지 않습니다.
- 당일 탭의 `일자` 는 항상 **오늘 날짜**로 적힙니다.
- 시트에 직접 붙여 넣어도 됩니다. 당일 탭은 `일자` 가 비어 있으면 오늘로 봅니다
  (다운로드 파일에는 날짜 열이 없어 그대로 붙여 넣을 수 있습니다).
- `1,234` 콤마 숫자와 `0.22%` 퍼센트 표기를 그대로 받습니다.

**날짜는 항상 한국 시간 기준입니다.** Streamlit Cloud 는 UTC 로 도는데, 한국 새벽 0~9시에는
서버 날짜가 하루 뒤처집니다. 그래서 `date.today()` 대신 `core.util.today_kst()` 를 씁니다.

## 집계 규칙

- 매칭: DB `utm_content` = `kakaopay_ad{세트}-{소재}` ↔ 소재명 `{접두어}{세트}_ad{소재}`
  (`채무조정_ad6` = 세트1, `채무조정2_ad6` = 세트2. 세트가 다르면 다른 소재)
- **DB단가 = 소진 ÷ DB**, 0건은 `-`. 합계 단가도 총소진÷총DB (개별 단가의 평균이 아님)
- DB 0건 미전환 소재도 표에 모두 남습니다
- 같은 (세트, 번호) 키를 가진 소재가 둘이면 소진이 큰 쪽에만 DB를 배정
- 소재는 **소재명 기준**으로 묶습니다. 세트명이 바뀌어도 기간 조회에서 한 소재가 두 줄로
  갈라지지 않습니다
- `테스트` 가 들어간 광고그룹은 기본 제외 (사이드바에서 포함 가능)
- 사이드바 보정: `소재명 금액` 으로 CPC 수정 전 지출 차감, `소재명 건수` 로 DB 직접 지정
- 상태 분류는 **승인은 `승인` 열**, 나머지는 `접수` 열의 값에 단어가 들어있는지로 봅니다.
  비교 전 공백을 지우므로 `미팅 확정` = `미팅확정` 이고, 부분 일치라 `미팅확정v2` 도 걸립니다.

  | 구분 | 보는 열 | 걸리는 단어 |
  |---|---|---|
  | 승인 | `승인` | 승인예정 · 승인완료 |
  | 미팅 | `접수` | 미팅확정 (v2, v3 포함) |
  | 접수 | `접수` | 접수완료 · 담보접수 · 법인파산접수 · 미팅보류 · 협의중 · 관리 **+ 미팅확정** |
  | 진행불가 | `접수` | 접수불가 · 채무미비 · 자산과다 · 소득미비 · 소득증빙불가 · 면책5년미만 · DTI100%미만 · 채무조정중 · 장기연체 |

- **구분은 배타가 아닙니다.** 깔때기라서 뒷단계가 앞단계를 포함합니다 - 미팅확정된 건은
  미팅에도, 접수에도 셉니다. 그래서 `접수 >= 미팅` 이고, 헤드라인의 '접수 이상' 은 접수와 같습니다.

## 설정

### 서비스 계정 (한 번만)

시트가 비공개라 서비스 계정으로 읽고 씁니다. **Sheets API 하나만** 켜면 됩니다
(Drive API 는 필요 없습니다).

1. https://console.cloud.google.com > 새 프로젝트
2. **API 및 서비스 > 라이브러리** > `Google Sheets API` > **사용**
3. **사용자 인증 정보 > 서비스 계정 만들기** > **키 추가 > JSON** > 다운로드
4. 파일명을 `service_account.json` 으로 바꿔 이 폴더에 넣기
5. 시트 두 개에 그 계정 이메일을 공유
   - 광고 시트: **편집자** (앱이 써야 함)
   - 전환(DB) 시트: **뷰어**

### 내 PC 에서 실행

```
..\venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py            # 또는 run_dashboard.bat
```

`config.json` 의 `ad_sheet_id` 에 광고 시트 ID 를 넣습니다(주소창 `/d/` 와 `/edit` 사이).

### 팀 공유 (Streamlit Cloud)

1. 이 폴더를 GitHub **비공개** 저장소에 올리기 (`.gitignore` 로 키와 개인정보는 제외됨)
2. https://share.streamlit.io > New app > Main file path `app.py`
3. **Advanced settings > Secrets** 에 아래 명령의 출력을 붙여넣기
   ```
   python make_cloud_secrets.py "팀에게알려줄비밀번호"
   ```
4. Deploy > `https://<앱이름>.streamlit.app`

`app_password` 를 넣으면 비밀번호를 물어봅니다. 비워 두면 잠그지 않습니다.

## 파일

| 경로 | 역할 |

| `app.py` | 대시보드 (업로드 · 집계 · 차트 · 리포트) |
| `sources/ad_sheet.py` | 광고 시트 읽기/쓰기 (당일 탭 / 마감 탭) |
| `sources/db_sheet.py` | 전환 시트 읽기 (서비스 계정) |

| `core/metrics.py` | 매칭·계산 규칙 (순수 함수) |
| `core/util.py` | 숫자·날짜·헤더 정규화 |
| `make_cloud_secrets.py` | 배포용 Secrets 생성 |
| `tests/` | pytest 62개 |

## 자주 나는 문제

| 증상 | 해결 |
|---|---|
| `광고 시트가 연결되지 않았습니다` | Secrets 또는 `config.json` 의 `ad_sheet_id` 확인 |
| `[gcp_service_account] 가 온전하지 않습니다` | Secrets 를 부분만 붙여넣음. 파일 전체를 다시 복사 |
| `시트에 쓰지 못했습니다` | 광고 시트에 서비스 계정이 **편집자**로 공유돼 있어야 함 |
| 매칭 안 된 DB가 많음 | `매칭 안 된 DB` 탭에서 utm_content 오타 확인 |
| 숫자가 그대로 | 위쪽 **시트 다시 읽기** (2분 캐시) |
